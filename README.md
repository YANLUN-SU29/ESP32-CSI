# ESP32 Wi-Fi CSI Monitor (ESP32 微波感測與視覺化系統)

## 📌 專案簡介
本專案是一個輕量級的 Wi-Fi CSI (Channel State Information) 擷取與視覺化系統。
透過 ESP32 開發板擷取 2.4GHz Wi-Fi (OFDM 52 條子載波) 的底層實體層訊號，並利用 Python 進行即時的 I/Q 複數解碼、環境去背與 2D 熱力圖視覺化，將無形的微波擾動轉化為肉眼可見的物理特徵。同時具備 CSV 自動錄影功能，可用於後續機器學習模型的資料收集。

## 🛠️ 硬體設備與環境
*   **發射端 (Tx):** MERCUSYS N300 (MW302R) 路由器
    *   環境鎖定：Channel 6, 20MHz 頻寬。
    *   硬體逼近：信標間隔 (Beacon Interval) 設為最低 `40ms`，確保高頻率微波廣播。
*   **接收端 (Rx):** ESP32 NodeMCU-32S 開發板
*   **監測端:** Windows PC (Python 環境)

## ✨ 已實現的核心技術
1.  **TCP 敲門激發機制 (TCP Knocking):**
    為了解決 ESP32 底層 CSI 引擎過濾廣播封包的問題，開發板會持續向路由器的 Port 80 發起 TCP 連線，強迫路由器回傳單播 (Unicast) 封包，達成極高頻率且穩定的 CSI 數據觸發，無需依賴外部設備 Ping。
2.  **I/Q 複數解碼至真實振幅:**
    將 ESP32 輸出的原始交錯陣列 `[I1, Q1, I2, Q2...]`，透過畢氏定理 ($Amplitude = \sqrt{I^2 + Q^2}$) 轉換為真實距離振幅，消除未解碼時的馬賽克雜訊。
3.  **動態背景消除演算法:**
    於 Python 端即時運算 `data_matrix - baseline`，消除環境中靜態物體（如牆壁、電腦機殼）的恆定微波反射，乾淨萃取出「人員移動」所產生的多徑效應 (Multipath Fading) 波紋。
4.  **先濾波、再 PCA 融合（順序關鍵）:**
    先將每條子載波帶通濾到目標頻段，**之後**才用主成分分析 (PCA) 融合為 PC1 波形。
    順序不可顛倒：原始振幅的變異量由寬頻雜訊與 AGC 漂移主導，遠大於胸腔起伏造成的微弱調變，
    若先做 PCA，PC1 會鎖定雜訊主軸而非生理訊號。實測 30 筆資料顯示「先融合再濾波」完全分不出
    有無人員（呼吸組 3.48 vs 空房間 3.60），改為「先濾波再融合」後才明顯分離（65.90 vs 3.45）。
    融合前並會自動剔除全程恆為 0 的 null/guard 子載波（ESP32 HT20 CSI 固有的無效通道）。
5.  **多層訊號清洗管線:**
    Rolling MAD 離群值偵測 → 線性去趨勢 (Detrend) → Butterworth 帶通濾波，有效抑制 EMI 突波產生的「漣漪假象」。
6.  **客觀偵測信心指標:**
    帶通濾波後的波形**永遠**看起來像正弦波，無論有沒有人，因此不能靠肉眼判讀。
    改以兩項可量化指標判定：**峰值突出度**（最強子載波在目標頻段的峰值 / 帶內雜訊中位數）
    與**載波共識度**（前 10 強子載波是否獨立收斂到同一頻率）。
    以 20 筆呼吸 / 5 筆閉氣 / 5 筆空房間校準，突出度門檻 20 可達零誤報。
7.  **實測取樣率換算:**
    離線分析時直接依錄製檔案的 `Timestamp` 欄位計算實際 fps（總幀數 / 總時長），而非假設固定值，讓時間軸與濾波器截止頻率更貼近真實錄製狀況。
8.  **即時斷點偵測:**
    `monitor.py` 錄製時會用高精度計時器量測每筆樣本的實際到達間隔，超過 0.5 秒（例如 Wi-Fi/TCP 重連造成的資料空窗）就即時印出警告並累計次數，錄製當下就能發現訊號中斷，不必等離線分析才發現整段資料已受損。
9.  **依實測佈局擷取子載波:**
    韌體輸出 384 bytes = 192 條子載波，由 LLTF / HT-LTF / STBC-HT-LTF2 三個 64 條區塊組成
    （可用 `csi_layout_probe.py` 重新量測確認）。擷取範圍不再寫死偏移量，而是依實測佈局選取：
    剔除各區塊的 DC 離群值（LLTF 的 DC 振幅達 134.4，區塊中位數僅 17.6）與保護頻帶，
    並捨棄與 HT-LTF 逐條相關係數達 0.902 的冗餘 STBC 區塊，最終取
    **LLTF 54 條 + HT-LTF 56 條 = 110 條**（HT-LTF 與 LLTF 相關性僅 0.06，屬獨立的通道量測）。
    舊版寫死 `amplitudes[5:57]`，存了 9 條恆為零的保護頻帶、又把視窗兩端切在滿振幅上，實際可用僅 43 條。
10. **韌體中繼資料與關閉省電:**
    韌體改以 `CSI_V2,<len>,<rssi>,<sig_mode>,<csi...>` 格式輸出，PC 端才能確認子載波佈局、
    剔除長度不一致的封包並診斷連線品質；同時關閉 Wi-Fi modem sleep (`WiFi.setSleep(false)`)，
    避免射頻在信標間隔之間休眠造成取樣不均勻。

## 🚀 使用方法

### 1. ESP32 接收端設定
1. 使用 Arduino IDE 開啟 `firmware.ino`。
2. 將 `ssid` 與 `password` 修改為發射端路由器的設定。
3. 燒錄至 ESP32 後，**務必關閉序列埠監控視窗**。

### 2. Python 監測端設定
1. 安裝所需套件：
   ```bash
   pip install -r requirements.txt
   ```
2. 執行監控程式：
   ```bash
   # 互動模式（程式會問你要錄哪個動作）
   python monitor.py

   # 命令列模式（直接指定標籤）
   python monitor.py Walking
   ```
3. 程式啟動後會自動掃描 COM Port 並連線 ESP32。
4. 錄製的 CSV 資料會自動儲存至 `data/` 資料夾。
5. 錄製過程中若偵測到超過 0.5 秒的訊號斷點，終端機會即時印出警告。
6. 關閉視覺化視窗即可結束錄製，終端機會顯示錄製統計（含有效筆數、解析丟棄筆數、訊號斷點次數）。

### 3. 離線數據分析 (事後分析)
錄製完成後，可使用 GUI 分析工具回顧任何 CSV 資料：
```bash
python analyzer_gui.py
```
開啟後點擊「載入 CSV 檔案」即可載入，程式提供 **4 種分析模式**透過 RadioButton 一鍵切換：

| 模式 | 頻段 | 用途 | 是否已校準 |
|------|------|------|------------|
| 大動作 | 0.05 ~ 5.0 Hz | 走動、起立坐下等肢體運動偵測 | ✗ |
| 呼吸 | 0.15 ~ 0.4 Hz | 靜止人員的微體徵 (呼吸) 萃取 | ✓ |
| 心跳 | 0.8 ~ 2.0 Hz | 極微體徵 (心跳) 偵測嘗試 | ✗ |
| 空房間基準 | 0.05 ~ 5.0 Hz | 確認無人時底噪是否平坦 | ✗ |

> 突出度會隨頻段寬度系統性改變，因此判定門檻只在有 ground truth 的頻段成立。
> 目前僅呼吸頻段完成校準，其餘頻段 GUI 會標示「尚無實測校準」，數值僅供不同檔案間比較。

**分析結果面板**會直接給出三個數字與一句判定：

| 指標 | 意義 |
|------|------|
| 推估頻率 | 前 10 強子載波峰值頻率的中位數（比單看融合峰值穩定，實測 ±0.1~0.6 次/分） |
| 峰值突出度 | 最強子載波的帶內峰值 / 帶內雜訊中位數 |
| 載波共識度 | 前 10 強子載波中，峰值頻率彼此一致的比例 |

每次分析會顯示三層圖表：
1. **全景有效子載波疊加** — 觀察多徑衰落與整體變異，並標示該頻段最強的一條
2. **目標頻段融合波形** — 先帶通、再 PCA 融合的結果
3. **功率頻譜 (Welch PSD)** — 縱軸已正規化為突出度倍率，可直接對照判定門檻線

> ⚠️ 判讀時請以第 3 張圖為準。第 2 張的帶通波形**無論有沒有人都會像正弦波**，
> 空房間資料同樣會呈現規律起伏，這正是需要客觀指標的原因。

### CSV 資料格式
新版（110 條子載波）每個 CSV 檔案包含 111 欄：
| 欄位 | 說明 |
|------|------|
| `Timestamp` | 錄製時間戳 (HH:MM:SS.ffffff，微秒精度) |
| `L1`~`L27`, `L37`~`L63` | LLTF 區塊 54 條子載波的振幅（數字為原始振幅索引） |
| `H65`~`H92`, `H100`~`H127` | HT-LTF 區塊 56 條子載波的振幅 |

> 舊版格式為 53 欄（`Timestamp` + `Sub_0`~`Sub_51`），`analyzer_gui.py` 兩種都能讀取
> （它以動態剔除全零欄位的方式處理，不寫死欄數）。
> 註：判定門檻是以舊版 43 條可用子載波的資料校準的，改用 110 條後需重新校準
> —— 依現有資料外推，空房間的最強突出度約由 9.4 升至 11.0，門檻 20 仍有餘裕。
